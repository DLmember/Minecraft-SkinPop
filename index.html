使用说明

生成皮肤 GIF

  1. 输入 Minecraft Java 版正版游戏名，点击「获取皮肤」；也可以上传 PNG 皮肤。
  2. 选择动作。拖动预览可调整视角，重置按钮恢复该动作的默认视角。
  3. 选择背景、尺寸和循环时长，生成并下载 GIF。点击「下载全部 GIF（ZIP）」可一次生成全部 12 个动作，每个动作使用默认视角和各自保存的循环时长。

本地版可直接双击 SkinPop.html。上传皮肤、预览、GIF 和 ZIP 导出均可离线使用；查询正版账号需要联网。

支持 Steve 4 像素粗胳膊、Alex 3 像素细胳膊及完整双层皮肤。支持 64×64、64×32 及等比例高清 PNG。账号按模型信息识别，本地文件按贴图识别，可手动切换。

账号查询使用 NeedCoolerShoes、Mojang、Ashcon 和 Minetools，错峰请求并采用最先完整加载成功的结果；名称会发送给查询服务，第三方服务可能有缓存。本地皮肤和动图不上传。

所有动作支持 0.5、1、1.5、1.6、2、3、4 秒循环，时长按动作分别保存。默认全身旋转、头部旋转为 1.5 秒；行走、快速潜行、死亡、复活、爆炸为 2 秒；跳劈、旋转压缩、坐姿点头为 1 秒。快速潜行每个循环完成 10 次站蹲，无中间过渡；默认站立、蹲下各保持 0.1 秒。坐姿点头每个循环完成两次相同的线性往返，旋转压缩按余弦曲线在 100%–40% 间变化。

死亡烟雾与爆炸使用 Java 1.21.4 原版粒子贴图序列。导出按完整动作范围自动构图，GIF 支持纯色或透明背景；透明度为二值，棋盘格不会写入文件。
