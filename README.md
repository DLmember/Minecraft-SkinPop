# SkinPop · Minecraft 皮肤动图工坊

淡蓝色卡通风格的纯静态网页，输入 Minecraft Java 版正版游戏名或上传 PNG 皮肤，在浏览器中预览并生成 GIF。无需登录，也不需要自建后端。

## 本地启动

直接双击项目根目录的 **SkinPop.html** 即可使用，无需安装 Node.js 或启动服务器。这个单文件包含渲染库、GIF 编码器、ZIP 打包库、样式和原版粒子资源，可以单独复制到其他电脑。

上传 PNG 皮肤、预览、GIF 和 ZIP 导出均可离线运行。查询正版账号需要联网。推荐新版 Chrome 或 Edge，并开启 WebGL / 硬件加速。

开发或修改源代码时，需要 Node.js 20.19+ 或 22.12+：

```sh
npm install
npm run dev
```

开发地址默认是 http://127.0.0.1:5173 。源文件 `index.html` 需通过开发服务器打开；交付文件 `SkinPop.html` 可直接双击。

## 静态部署

在线网站：https://dlmember.github.io/Minecraft-SkinPop/

GitHub 仓库：https://github.com/DLmember/Minecraft-SkinPop

GitHub Pages 从 `main` 分支的 `docs/` 目录发布。修改后运行 `npm run build:local` 更新本地单文件，再运行 `npm run build:pages` 更新网站文件，将改动提交并推送到 GitHub 即可发布。

```sh
npm run build
npm run preview
npm run build:local
```

`npm run build` 输出独立的 `dist/index.html`，可托管或直接打开。`npm run build:local` 同时将其复制为根目录的 `SkinPop.html`。

## 功能

- 正面全身水平旋转。
- 斜上方俯视头颅水平旋转。
- 斜侧方行走。
- 斜侧方持钻石剑跳劈。
- 吃苹果：使用 Java 1.21.4 原版苹果的完整像素贴图和碎屑，默认 32 ticks / 1.6 秒吃完一颗，每 4 ticks 啃食一次；支持独立调速和记忆。抬手和粒子轨迹由页面实现。
- 斜侧方快速潜行：每个循环完成 10 次站蹲，无中间过渡；默认 2 秒循环，站立、蹲下各保持 0.1 秒。循环时长档位可调整速度。导出将相同姿势的保持时间合并，使用 20 帧，避免最快档位的过短帧延时被浏览器拉长。
- 平视全身旋转压缩：高度沿余弦曲线在 100%–40% 之间往返，脚底位置固定。
- 斜侧方坐姿点头：头部按三角波匀速上下运动，每个循环完成两次相同的线性往返。
- 死亡：变红、侧倒、消失，随后使用原版 poof/smoke 粒子序列出现一缕烟。
- 复活：死亡动作完整倒放，烟雾收拢、人物出现、起身并恢复肤色；默认 2 秒，可独立调速和记忆。
- 爆炸：平视玩家原地膨胀、抖动、苦力怕式白色闪烁，随后消失并播放原版 explosion 粒子序列。
- 完整双层皮肤：头部、身体、双臂、双腿的外层跟随对应部位运动，可整体开关。
- Steve 4 像素粗胳膊 / Alex 3 像素细胳膊，账号依据模型元数据识别，本地文件按贴图推断，支持手动覆盖。
- 支持 64×64 / 64×32 皮肤及 2 的整数次幂高清版本，最大宽度 1024，文件上限 8 MB。
- 实时预览、暂停、旋转、缩放、重置视角。
- 五种纯色背景或透明背景；256 / 384 / 512 像素尺寸；10 / 20 / 25 / 30 FPS，以及 GIF 兼容输出档；0.5 / 1 / 1.5 / 1.6 / 2 / 3 / 4 秒完整循环。默认帧率为 30 FPS，帧率设置及各动作时长使用 localStorage 保存；刷新或重新打开时恢复，存储不可用时保留本次打开期间的选择。GIF 以百分之一秒存储帧延迟，而 Chromium / Firefox 会把不超过 10 ms 的帧延迟扩展为 100 ms；为避免原 60 FPS 设置产生忽快忽慢及超长播放时间，60 FPS 选项生成 50 FPS 的均匀 20 ms 帧，保持准确循环时长。默认全身旋转、头部旋转为 1.5 秒；行走、快速潜行、死亡、复活、爆炸为 2 秒；跳劈、旋转压缩、坐姿点头为 1 秒；吃苹果为 1.6 秒。0.5 秒 / 25 FPS 输出 13 帧，通过分配 30/40 ms 帧间隔保证总时长仍为 500 ms。
- 导出根据整个动作周期自动放大和居中，在主要方向保留约 2%–3% 边距。镜头在同一循环中保持固定，保留跳跃和压缩的实际变化。
- 透明 GIF 使用独立透明索引，避免删除与背景相同的皮肤颜色；逐帧清除背景，避免拖影。棋盘格仅用于预览。
- 本地 GIF 编码、进度显示、取消、生成结果预览及下载；手机布局。
- 一键生成全部 12 个动作并下载为一个 ZIP。使用当前皮肤、模型、外层和背景设置，每个动作采用自身默认视角和各自保存或默认的时长；按序生成以控制内存，可取消，并保留原来的动作选择。ZIP 内按编号和动作名区分文件。

扭腰在 `src/waist.js` 中独立实现，以用户提供的桌宠 v2.5 `native/src/render.rs` 的 `base_body`、`body`、`torso_space` 和部件绘制矩阵为参考；资源包 `player.jem` 提供稳定强度 0.15、身体起伏、肩点反向升降和头/手臂延迟相位。统一将桌宠脚底坐标换算为 skinview3d 的颈部坐标，保留原生部件层级、纹理和双层皮肤；身体绕上端旋转，头和手臂使用各自的独立变换，手臂补偿粗细模型原有的横向网格偏移。头部采用不追踪鼠标的中立朝向。腿部完整采用桌宠原始变换链：基础蹲姿 → 横移 `-12 × sin(t) × 0.15` → 侧摆 `sin(t) × 0.15` → 蹲姿腿角 `-0.24` 弧度；不再固定双脚，也不抵消原有的脚部移动。动画频率继续由 BPM 控件设置，直接循环稳定阶段，不模拟潜行等待和渐入，也不分发资源包或桌宠程序。

`node tests/waist-reference.mjs`（可用 `TEST_URL` 指定开发服务器）通过独立标量坐标变换核对粗/细手臂、内/外层全部网格顶点，并检查循环接缝和切换全部动作后的姿势恢复；生成正侧面对照图到 `artifacts/waist-rebuilt-contact-sheet.png`。本地单文件的按钮、GIF 导出及 BPM 持久化分别通过 `tests/local-revision.mjs` 和 `tests/bpm.mjs` 检查。

移动端依次显示皮肤、动作、预览、导出设置。单张生成进度直接显示在生成按钮上，完成后同一按钮变为下载按钮。

扭腰和旋转压缩使用「BPM（每分钟节拍数）」输入，支持任意正数、一位小数（最小 0.1，无上限）。每循环两拍，循环秒数为 `120 / BPM`；60 BPM 为 2 秒，180 BPM 为 2/3 秒。两动作的速度独立保存，预览、单张导出与 ZIP 共用该设置；原先保存的时长自动换算为 BPM，默认扭腰 200 BPM、旋转压缩 120 BPM。其他动作继续选择循环时长。GIF 时长按格式的百分之一秒精度取整。

扭腰骨架适配使用上述桌宠部件矩阵，保留腿部的原始随动，不添加锁脚或反算髋部位置的修正。爆炸以人物几何中心均匀放大，最大放大增量由 85% 降至 21.25%（原增量减少 75%），不再向上移动人物。

## 账号查询与跨域

优先尝试 NeedCoolerShoes 的 `/api/skin/{name}`，一次请求返回完整 PNG，并从响应头读取 UUID 和 classic/slim 模型。250 / 600 / 1000 ms 后分别启动 Mojang、Ashcon、Minetools；采用最先完成查询、图片下载、解码和尺寸验证的结果，取消其余请求，总请求期限为 10 秒。单个服务返回 404、图片下载失败或图片损坏，不会阻止其他服务继续尝试。

第三方服务可能有缓存，无法保证刚更换的皮肤立即同步。不会用默认皮肤冒充查询成功。只在提交游戏名时请求服务，本地皮肤和动图不上传。

如果所有服务都不可用，保留当前皮肤并显示错误；仍可使用本地上传。账号查询仅针对 Java 版游戏名，不能用微软邮箱或基岩版 Xbox 名称查询。网络条件、上游限流和服务可用性会影响查询。

## 技术与验证

Vite + 原生 JavaScript，skinview3d / Three.js 渲染双层皮肤，gifenc 逐帧本地编码，fflate 打包 ZIP。帧间让出执行时间用于响应进度与取消；构建时内联脚本、样式与贴图，字体使用系统字体，无运行时 CDN 依赖。预览与导出共用确定性的动作函数。钻石剑和烟雾、爆炸使用 Minecraft Java 1.21.4 原版贴图，来源与哈希见 `src/assets/README.md` 及粒子 provenance 文件；粒子位移和动画时序由页面实现。

```sh
node tests/smoke.mjs
node tests/integration.mjs
node tests/eating.mjs
node tests/skin-fallback.mjs
node tests/export-regression.mjs
node tests/offline-batch.mjs
```

默认使用已安装的 Chrome。`offline-batch.mjs` 在禁用网络的浏览器中直接打开本地 HTML，验证各动作默认时长、独立时长持久化、上传皮肤、ZIP 内 11 个真实 GIF 的独立时长、透明度、无裁切、可调速潜行、批量取消与状态恢复、移动端布局和无网络资源请求。其他测试使用开发服务：`smoke.mjs` 验证 GIF 下载与基本控件；`integration.mjs` 验证模型、外层、查询回退和文件验证；`export-regression.mjs` 检查动作构图。真实网络结果不影响模拟查询用例。

`artifacts` 保存界面截图、动作采样图和测试 GIF，不是部署必需文件。
